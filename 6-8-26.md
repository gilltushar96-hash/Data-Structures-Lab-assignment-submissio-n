# Documentation: 6-8-26.cpp

## Purpose

This program implements a list ADT using an integer array of capacity 100. The
array uses `-1` as an end marker, so the stored list is treated as the values that
appear before the first `-1`.

## Available Operations

The menu in `main()` provides these operations:

1. Create the list by entering values and finishing with `-1`
2. Display the list
3. Search for a value and print its index, or `-1` if it is absent
4. Insert a value at an index, before a selected value, or after a selected value
5. Delete a selected value from the list
6. Display the current list size
7. Exit by entering `-1`

The implementation separates these operations into `create()`, `display()`,
`search()`, `insert()`, `remove()`, and `sizeofarray()` functions.

## Compile and Run

Using g++:

```bash
g++ 6-8-26.cpp -o list_adt
./list_adt
```

On Windows with MinGW:

```powershell
g++ 6-8-26.cpp -o list_adt.exe
.\list_adt.exe
```

## Important Input Note

Use integer values only. Do not store `-1` as a normal list value because it is
reserved as the end marker. The list must also remain within the array capacity.
