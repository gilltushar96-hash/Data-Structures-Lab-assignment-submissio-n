# Documentation: 30-7-26.cpp

## Purpose

This program demonstrates basic list operations using a fixed-size integer array:

- Insert a value at a selected index
- Delete a value at a selected index
- Search for a value and report its index

## How It Works

The program starts with the array `{3, 2, 1, 4, 5}`. It then asks the user for:

1. The index and value to insert
2. The index of the value to delete
3. The value to search for

When inserting, elements are shifted to the right to make space. When deleting,
elements after the selected index are shifted left. The search operation scans the
array from the beginning and stops after finding the first matching value.
